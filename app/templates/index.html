Sobre o projeto

Uma interface simples para acompanhar moedas

Este projeto permite consultar cotações de moedas e acompanhar a variação de valores com gráficos interativos. A proposta é oferecer uma experiência limpa, moderna e fácil de usar, tanto em desktop quanto em dispositivos móveis.

Consulta rápida

Pesquise valores com poucos cliques e de forma objetiva.

Leitura visual

Entenda tendências com gráficos claros e organizados.

Base para evolução

Estrutura pronta para receber novas moedas, filtros e métricas.
